3Team Responsibilities — บทบาทของทีม eTrade
แสดงหมวดบทบาทด้วยแถบสีในคอลัมน์แรกเท่านั้น โดยแต่ละงานแสดงเพียงครั้งเดียว
บทบาททีม eTrade งาน ผู้รับผิดชอบหลัก สิ่งที่ทีม eTrade ทำ ช่วงเวลา / สถานะ
eTrade ทำ / ร่วมทำ Thailand-hosted DPP ASEAN Workshop eTrade + IC + พี่กาย + มะขาม นำผลจากโครงการ DPP มา package เป็น Thailand DPP Use Case สำหรับ workshop ระดับ ASEAN ต.ค.70
eTrade ทำ / ร่วมทำ APEC ACCEPT / Thailand–Singapore Invoice ทีม eTrade Review invoice content และทำ engagement กับภาครัฐ/เอกชน; งาน APEC ครอบคลุม CO / Invoice / eBL / Customs Bond FY2570 / external schedule
ยังไม่ระบุเดือน
eTrade ทำ / ร่วมทำ TLX follow-up ETDA / พี่นิด on call ติดตามคุณรัชเดชและความคืบหน้าที่เกี่ยวข้องกับ TLX ตามจังหวะงาน Ongoing
eTrade ทำ / ร่วมทำ Alien Technology ทีม eTrade แลกเปลี่ยนข้อมูลระบบ และหารือความเป็นไปได้ในการต่อยอดไปสู่ real-use โดยไม่มีงบประมาณเพิ่มเติม TBC
eTrade ทำ / ร่วมทำ KPI 1 / KPI 2 mapping ทีม eTrade หารือและยืนยันว่าจะใช้ Action Plan Track และ Durian Cross-border DPP Use Case เป็น evidence หลักของ KPI หรือไม่ พร้อมวาง evidence collection Pending team discussion
eTrade ทำ / ร่วมทำ China Invoice / ESCAP พี่นิด + ทีม eTrade ติดตาม ESCAP และสรุปประเภท Invoice / data / document requirement ฝั่งจีน เพื่อนำไปใช้กับ cross-border design, Prototype และ Pilot In progress

eTrade Support ข้อมูล CPTA Committee — Battery + Durian พี่นิด เตรียมผลโครงการ/ข้อมูล Battery + Durian, Real Transaction, interoperability และ lessons learned เพื่อใช้ประกอบการรายงาน พ.ย.70 (คาด)
eTrade Support ข้อมูล DEPA Assessment พี่โบนัส ทีม Trade สนับสนุนข้อมูลตามประเด็น/คำขอที่ใช้ประกอบการประเมินของ DEPA Ongoing / ตาม request

Collaboration IC — Agreement clarification พี่โบนัส ทำงานร่วมกับ IC เพื่ออธิบายความแตกต่างของ agreements / กรอบความร่วมมือที่เกี่ยวข้อง และ align ความเข้าใจสำหรับการทำงานร่วมกัน TBC
4Other Ongoing / TBC Work — Not Shown on Timeline
ส่วนนี้ใช้บอกเฉพาะว่า “มีงานอยู่แต่ยังไม่ใส่บนแกนเวลา”; รายละเอียดบทบาท eTrade ให้ยึดตารางข้อ 3
  • APEC ACCEPT / Thailand–Singapore Invoice — อยู่ในแผน FY2570 ตาม external schedule; timing ยังไม่ยืนยัน
  • TLX — ติดตามคุณรัชเดช / ETDA follow-up / พี่นิด on call
  • DEPA Assessment — พี่โบนัส lead; ทีม Trade support data ตาม request
  • Alien Technology — แลกเปลี่ยนข้อมูลระบบ / พิจารณาต่อยอด real-use; no budget
  • IC Collaboration — agreement clarification (พี่โบนัส) + data/support needs (IC + eTrade)
Note: งานกลุ่มนี้ไม่แสดงบน timeline เพราะยังไม่มีช่วงเวลาดำเนินงานที่ยืนยัน และจะเพิ่มเมื่อมี schedule ชัดเจน
