ทุเรียนหมอนทอง ล็อต A26 → จีน

    
ระดับตัวระบุ: ล็อต (idGranularity: "batch") หนึ่งล็อต = 1 คันรถห้องเย็น 1,000 กล่อง 18,000 กก. คัดจาก 3 แปลง GAP

    

    

  


  
  

    
แบตเตอรี่ EV 75 kWh → EU

    
ระดับตัวระบุ: รายชิ้น (idGranularity: "item") ตามที่ Battery Passport ของ EU ต้องการ แต่ใบรับรองบางใบ เช่น carbon footprint ออกที่ ระดับรุ่น แล้วทุกก้อนในรุ่นนั้นอ้างถึงใบเดียวกัน

    

    

  


  
  

    
สองเคสต่างกันตรงไหน

    

      
ทุเรียน → จีนแบตเตอรี่ → EU

      
        
ระดับ ID ของ DPPล็อต /01/{GTIN}/10/A26รายชิ้น /01/{GTIN}/21/{serial}

        
DFR สำคัญที่สุดแปลง GAP (พิกัด ขอบเขตแปลง) + โรงคัด GMPโรงงานประกอบ + เหมือง/โรงถลุงต้นน้ำ

        
DCC หลักGAP (ระดับแปลง), ผลตรวจล็อต (ระดับล็อต)Carbon footprint, UN 38.3 (ระดับรุ่น)

        
DTE หลักMake: 3 แปลง → ล็อต A26 · Move: สวน → ด่านMake: เซลล์ → แพ็ก · Move: เรือ · Modify: SoH / ซ่อม / รีไซเคิล

        
เอกสารการค้าที่ผูกe-Phyto, invoice (TLX), ใบขน (NSW)ใบขน, EU DPP Registry

        
ช่วงชีวิตข้อมูลสั้น: เก็บ → ขาย ~ 2–3 สัปดาห์ยาว: 10+ ปี มีการอัปเดตระหว่างใช้งาน

        
ระดับการเข้าถึงสาธารณะ / คู่ค้า (invoice) / หน่วยงานรัฐ (e-Phyto)สาธารณะ / ผู้มีส่วนได้เสีย (recycler) / หน่วยงานรัฐ

        
จุดตรวจเฉพาะMass balance ล็อต ↔ ผลผลิตแปลงRecycled content, carbon class ตาม Battery Regulation

      


    
ลำดับที่ข้อมูลเกิด (ใช้ได้ทั้งสองเคส)

    

      
ลำดับเกิดอะไรCredentialต้องมีก่อน

      
        
1ขึ้นทะเบียนสถานที่DFRDID + DIA ของเจ้าของสถานที่

        
2รับรองสถานที่DCC (assessedFacility)ID สถานที่จาก DFR

        
3ผลิต / แปรรูป / ประกอบDTE MakeEventID ของวัตถุดิบ (input) และ ID สินค้าใหม่ (output)

        
4ตรวจสินค้าDCC (assessedProduct)ID สินค้า

        
5ออกพาสปอร์ตDPPลิงก์ไป DCC, DFR, DTE ข้างบน

        
6ลงทะเบียนลิงก์IDR linkset / RegistryURL ของทุก credential

        
7ขนส่ง / ใช้งาน / ซ่อมDTE Move / ModifyID สินค้า

      

    
หลักสำคัญ: ไม่มี credential ใบไหน "รวม" ข้อมูลทุกอย่างไว้ DPP เป็นแค่จุดตั้งต้นที่มีลิงก์ไปใบอื่น ผู้ตรวจต้องเดินตามลิงก์และ verify ลายเซ็นทีละใบ ข้อมูลแต่ละส่วนจึงยังเป็นของผู้ออกเดิม
